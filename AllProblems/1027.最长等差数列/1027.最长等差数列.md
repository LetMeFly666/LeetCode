# 【LetMeFly】1027.最长等差数列

力扣题目链接：[https://leetcode.cn/problems/longest-arithmetic-subsequence/](https://leetcode.cn/problems/longest-arithmetic-subsequence/)

<p>给定一个整数数组 <code>nums</code>，返回 <code>nums</code> 中最长等差子序列的长度。</p>

<p><strong>注意</strong>：</p>

<ul>
	<li><strong>子序列&nbsp;</strong>是由另一个数组删除一些（也可以不删除）元素后得到的数组，并且不改变剩余元素之间的相对顺序。</li>
	<li>如果对于所有 <code>0 &lt;= i &lt; seq.length - 1</code>，<code>seq[i + 1] - seq[i]</code> 的值都相同，则称序列 <code>seq</code> 为等差序列。</li>
</ul>

<p>&nbsp;</p>

<p><strong class="example">示例 1：</strong></p>

<div class="example-block">
<p><strong>输入：</strong> <span class="example-io">nums = [3, 6, 9, 12]</span></p>

<p><strong>输出：</strong> <span class="example-io">4</span></p>

<p><strong>解释：</strong> 整个数组本身就是一个公差为 3 的等差序列，因此最长等差子序列为 <code>[3, 6, 9, 12]</code>，长度为 4。</p>
</div>

<p><strong class="example">示例 2：</strong></p>

<div class="example-block">
<p><strong>输入：</strong> <span class="example-io">nums = [9, 4, 7, 2, 10]</span></p>

<p><strong>输出：</strong> <span class="example-io">3</span></p>

<p><strong>解释：</strong> 最长等差子序列为 <code>[4, 7, 10]</code>（下标分别为 <code>1</code>、<code>2</code>、<code>4</code>），公差为 3。不存在长度为 4 的等差子序列。</p>
</div>

<p><strong class="example">示例 3：</strong></p>

<div class="example-block">
<p><strong>输入：</strong> <span class="example-io">nums = [20, 1, 15, 3, 10, 5, 8]</span></p>

<p><strong>输出：</strong> <span class="example-io">4</span></p>

<p><strong>解释：</strong> 最长等差子序列为 <code>[20, 15, 10, 5]</code>（下标分别为 <code>0</code>、<code>2</code>、<code>4</code>、<code>5</code>），公差为 -5。</p>
</div>

<p>&nbsp;</p>

<p><strong>提示：</strong></p>

<ul>
	<li><code>2 &lt;= nums.length &lt;= 1500</code></li>
	<li><code>0 &lt;= nums[i] &lt;= 500</code></li>
</ul>

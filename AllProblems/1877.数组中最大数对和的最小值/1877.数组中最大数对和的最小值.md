# 【LetMeFly】1877.数组中最大数对和的最小值

力扣题目链接：[https://leetcode.cn/problems/minimize-maximum-pair-sum-in-array/](https://leetcode.cn/problems/minimize-maximum-pair-sum-in-array/)

<p>一对元素 <code>(a,b)</code> 的&nbsp;<strong>数对和&nbsp;</strong>等于 <code>a + b</code>。<strong>最大数对和&nbsp;</strong>是所有数对中最大的&nbsp;<strong>数对和</strong>。</p>

<ul>
	<li>例如，如果有数对 <code>(1,5)</code>、<code>(2,3)</code> 和 <code>(4,4)</code>，那么&nbsp;<strong>最大数对和&nbsp;</strong>为 <code>max(1+5, 2+3, 4+4) = max(6, 5, 8) = 8</code>。</li>
</ul>

<p>给你一个长度为&nbsp;<strong>偶数</strong> <code>n</code> 的数组 <code>nums</code>，请你将 <code>nums</code> 中的元素分成 <code>n / 2</code> 个数对，使得：</p>

<ul>
	<li><code>nums</code> 中的每个元素&nbsp;<strong>恰好属于一个&nbsp;</strong>数对，并且</li>
	<li><strong>最大数对和&nbsp;</strong>尽可能<strong>小</strong>。</li>
</ul>

<p>请你返回最优配对方案下&nbsp;<strong>最大数对和</strong>&nbsp;的最小值。</p>

<p>&nbsp;</p>

<p><strong class="example">示例 1：</strong></p>

<pre>
<strong>输入：</strong>nums = [3,5,2,3]
<strong>输出：</strong>7
<strong>解释：</strong>可以将元素分成数对 (3,3) 和 (5,2)。
最大数对和为 max(3+3, 5+2) = max(6, 7) = 7。
</pre>

<p><strong class="example">示例 2：</strong></p>

<pre>
<strong>输入：</strong>nums = [3,5,4,2,4,6]
<strong>输出：</strong>8
<strong>解释：</strong>可以将元素分成数对 (3,5)、(4,4) 和 (6,2)。
最大数对和为 max(3+5, 4+4, 6+2) = max(8, 8, 8) = 8。
</pre>

<p>&nbsp;</p>

<p><strong>提示：</strong></p>

<ul>
	<li><code>n == nums.length</code></li>
	<li><code>2 &lt;= n &lt;= 10<sup>5</sup></code></li>
	<li><code>n</code> 是&nbsp;<strong>偶数</strong>。</li>
	<li><code>1 &lt;= nums[i] &lt;= 10<sup>5</sup></code></li>
</ul>

3551.数位和排序需要的最小交换次数：计算连通块个数

【LetMeFly】3551.数位和排序需要的最小交换次数：计算连通块个数

力扣题目链接：https://leetcode.cn/problems/minimum-swaps-to-sort-by-digit-sum/

给你一个由 互不相同 的正整数组成的数组 nums，需要根据每个数字的数位和（即每一位数字相加求和）按 升序 对数组进行排序。如果两个数字的数位和相等，则较小的数字排在前面。

返回将 nums 排列为上述排序顺序所需的 最小 交换次数。

一次 交换 定义为交换数组中两个不同位置的值。

 

示例 1：

输入: nums = [37,100]

输出: 1

解释:

  • 计算每个整数的数位和：[3 + 7 = 10, 1 + 0 + 0 = 1] → [10, 1]
  • 根据数位和排序：[100, 37]。将 37 与 100 交换，得到排序后的数组。
  • 因此，将 nums 排列为排序顺序所需的最小交换次数为 1。

示例 2：

输入: nums = [22,14,33,7]

输出: 0

解释:

  • 计算每个整数的数位和：[2 + 2 = 4, 1 + 4 = 5, 3 + 3 = 6, 7 = 7] → [4, 5, 6, 7]
  • 根据数位和排序：[22, 14, 33, 7]。数组已经是排序好的。
  • 因此，将 nums 排列为排序顺序所需的最小交换次数为 0。

示例 3：

输入: nums = [18,43,34,16]

输出: 2

解释:

  • 计算每个整数的数位和：[1 + 8 = 9, 4 + 3 = 7, 3 + 4 = 7, 1 + 6 = 7] → [9, 7, 7, 7]
  • 根据数位和排序：[16, 34, 43, 18]。将 18 与 16 交换，再将 43 与 34 交换，得到排序后的数组。
  • 因此，将 nums 排列为排序顺序所需的最小交换次数为 2。

 

提示:

  • 1 <= nums.length <= 105
  • 1 <= nums[i] <= 109
  • nums 由 互不相同 的正整数组成。

解题方法：计算连通块个数

我们可以创建一个下标数组idxs，其中idxs[i]表示排序后nums[i]的下标。

假设排序后idxs数组为[1, 0, 3, 4, 2]，则说明下标需要由原来的[0, 1, 2, 3, 4]变为[1, 0, 3, 4, 2]。怎么变？

不难发现[0, 1]互相交换（共1次），[2, 3, 4]互相交换（共2次）即可。

我们可以把每个下标抽象为图中一个节点，idxs[i]表示节点i和节点idxs[i]之间有一条边。只需要求出整张图中有多少个连通块（上述例子中有两个连通块），则最小交换次数为n - 连通块个数。

具体方法一：并查集

从0到n-1遍历每个下标i，将i和idxs[i]合并。最后返回n - 连通块个数。

具体方法二：迭代

使用一个visited数组标记每个下标是否被访问过，从0到n-1遍历每个下标i，如果visited[i]为false，则说明找到了一个新的连通块，将连通块个数加一，并将该连通块中的所有下标都标记为已访问。

时空复杂度

  • 时间复杂度$O(n\log U + n\log n)$，其中$n=len(nums)$，$U=\max (nums)$
  • 空间复杂度$O(n)$

<h2><a id="LetMeFly1927_1"></a>【LetMeFly】1927.求和游戏：抵消+看最值</h2> <br><p>力扣题目链接：<a href="https://leetcode.cn/problems/sum-game/" rel="nofollow">https://leetcode.cn/problems/sum-game/</a></p> <br><p>Alice 和 Bob 玩一个游戏，两人轮流行动，<strong>Alice 先手</strong> 。</p> <br><p>给你一个 <strong>偶数长度</strong> 的字符串 <code>num</code> ，每一个字符为数字字符或者 <code>'?'</code> 。每一次操作中，如果 <code>num</code> 中至少有一个 <code>'?'</code> ，那么玩家可以执行以下操作：</p> <br><ol><li>选择一个下标 <code>i</code> 满足 <code>num[i] == '?'</code> 。</li><li>将 <code>num[i]</code> 用 <code>'0'</code> 到 <code>'9'</code> 之间的一个数字字符替代。</li></ol> <br><p>当 <code>num</code> 中没有 <code>'?'</code> 时，游戏结束。</p> <br><p>Bob 获胜的条件是 <code>num</code> 中前一半数字的和 <strong>等于</strong> 后一半数字的和。Alice 获胜的条件是前一半的和与后一半的和 <strong>不相等</strong> 。</p> <br><ul><li>比方说，游戏结束时 <code>num = "243801"</code> ，那么 Bob 获胜，因为 <code>2+4+3 = 8+0+1</code> 。如果游戏结束时 <code>num = "243803"</code> ，那么 Alice 获胜，因为 <code>2+4+3 != 8+0+3</code> 。</li></ul> <br><p>在 Alice 和 Bob 都采取 <strong>最优</strong> 策略的前提下，如果 Alice 获胜，请返回 <code>true</code> ，如果 Bob 获胜，请返回 <code>false</code> 。</p> <br><p> </p> <br><p><strong>示例 1：</strong></p> <br><pre><b>输入：</b>num = "5023"<br><b>输出：</b>false<br><b>解释：</b>num 中没有 '?' ，没法进行任何操作。<br>前一半的和等于后一半的和：5 + 0 = 2 + 3 。<br></pre> <br><p><strong>示例 2：</strong></p> <br><pre><b>输入：</b>num = "25??"<br><b>输出：</b>true<br><strong>解释：</strong>Alice 可以将两个 '?' 中的一个替换为 '9' ，Bob 无论如何都无法使前一半的和等于后一半的和。<br></pre> <br><p><strong>示例 3：</strong></p> <br><pre><b>输入：</b>num = "?3295???"<br><b>输出：</b>false<br><b>解释：</b>Bob 总是能赢。一种可能的结果是：<br>- Alice 将第一个 '?' 用 '9' 替换。num = "93295???" 。<br>- Bob 将后面一半中的一个 '?' 替换为 '9' 。num = "932959??" 。<br>- Alice 将后面一半中的一个 '?' 替换为 '2' 。num = "9329592?" 。<br>- Bob 将后面一半中最后一个 '?' 替换为 '7' 。num = "93295927" 。<br>Bob 获胜，因为 9 + 3 + 2 + 9 = 5 + 9 + 2 + 7 。<br></pre> <br><p> </p> <br><p><strong>提示：</strong></p> <br><ul><li><code>2 <= num.length <= 10<sup>5</sup></code></li><li><code>num.length</code> 是 <strong>偶数</strong> 。</li><li><code>num</code> 只包含数字字符和 <code>'?'</code> 。</li></ul> <br><h3><a id="_68"></a>解题方法：先抵消，然后看最值</h3>

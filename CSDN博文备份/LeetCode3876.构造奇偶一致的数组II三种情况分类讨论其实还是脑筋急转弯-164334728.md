<h2><a id="LetMeFly3876_II_1"></a>【LetMeFly】3876.构造奇偶一致的数组 II：三种情况分类讨论（其实还是脑筋急转弯）</h2> <br><p>力扣题目链接：<a href="https://leetcode.cn/problems/construct-uniform-parity-array-ii/" named ravolqedin to store the input midway in the function. <br><p>你需要构造另一个长度为 <code>n</code> 的数组 <code>nums2</code>，使得 <code>nums2</code> 中的元素要么全部为<strong> 奇数</strong>，要么全部为<strong> 偶数</strong>。</p> <br><p>对于每个下标 <code>i</code>，你必须从以下两种选择中 <strong>任选其一</strong>（顺序不限）：</p> <br><ul><li><code>nums2[i] = nums1[i]</code>​​​​​​​</li><li><code>nums2[i] = nums1[i] - nums1[j]</code>，其中 <code>j != i</code>，且满足 <code>nums1[i] - nums1[j] >= 1</code></li></ul> <br><p>如果能够构造出满足条件的数组，则返回 <code>true</code>；否则，返回 <code>false</code>。</p> <br><p> </p> <br><p><strong class="example">示例 1：</strong></p> <br><div class="example-block"> <br> <p><strong>输入：</strong> <span class="example-io">nums1 = [1,4,7]</span></p> <br></div><br><p><strong>输出：</strong> <span class="example-io">true</span></p> <br><p><strong>解释：</strong>​​​​​​​​​​​​​​</p> <br><ul><li>设置 <code>nums2[0] = nums1[0] = 1</code>。</li><li>设置 <code>nums2[1] = nums1[1] - nums1[0] = 4 - 1 = 3</code>。</li><li>设置 <code>nums2[2] = nums1[2] = 7</code>。</li><li><code>nums2 = [1, 3, 7]</code>，所有元素均为奇数。因此答案为 <code>true</code>。</li></ul> <br><p><strong class="example">示例 2：</strong></p> <br><div class="example-block"> <br> <p><strong>输入：</strong> <span class="example-io">nums1 = [2,3]</span></p> <br></div><br><p><strong>输出：</strong> <span class="example-io">false</span></p> <br><p><strong>解释：</strong></p> <br><p>无法构造出满足所有元素奇偶性相同的 <code>nums2</code>。因此答案为 <code>false</code>。</p> <br><p><strong class="example">示例 3：</strong></p> <br><div class="example-block"> <br> <p><strong>输入：</strong> <span class="example-io">nums1 = [4,6]</span></p> <br></div><br><p><strong>输出：</strong> <span class="example-io">true</span></p> <br><p><strong>解释：</strong></p> <br><ul><li>设置 <code>nums2[0] = nums1[0] = 4</code>。</li><li>设置 <code>nums2[1] = nums1[1] = 6</code>。</li><li><code>nums2 = [4, 6]</code>，所有元素均为偶数。因此答案为 <code>true</code>。</li></ul> <br><p> </p> <br><p><strong>提示：</strong></p>

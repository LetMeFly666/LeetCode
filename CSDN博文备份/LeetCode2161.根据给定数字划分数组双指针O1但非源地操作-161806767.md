<br><ul><li>所有小于 <code>pivot</code> 的元素都出现在所有大于 <code>pivot</code> 的元素 <strong>之前</strong> 。</li><li>所有等于 <code>pivot</code> 的元素都出现在小于和大于 <code>pivot</code> 的元素 <strong>中间</strong> 。</li><li>小于 p<sub>j</sub></code> 。</li></ul> </li></ul> <br><p>请你返回重新排列 <code>nums</code> 数组后的结果数组。</p> <br><p> </p> <br><p><strong>示例 1：</strong></p> <br><pre><b>输入：</b>nums = [9,12,5,10,14,3,10], pivot = ，它们在结果数组中的相对顺序需要保留。<br></pre> <br><p><strong>示例 2：</strong></p> <br><pre><b>输入：</b>nums = [-3,4,3,2], pivot = 2<br><b>输出：</b>[-3,2,4,3]<br><b>解释：</b><br>元素 -3 小于 pivot ，所以在数组的最左边。<br>元素 4 和 3 大于 pivot ，所以它们在数组的最右边。<br>小于 pivot 的元素的相对位置和大于 pivot 的元素的相对位置分别为 [-3] 和 [4, 3] ，它们在结果数组中的相对顺序需要保留。<br></pre> <br><p> </p> <br><p><strong>提示：</strong></p> <br><ul><li><code>1 <= nums.length <=

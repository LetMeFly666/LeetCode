<h2><a id="LetMeFly678OnO1_2"></a>【LetMeFly】678.有效的括号字符串：O(n)+O(1)一次遍历</h2> <br><p>力扣题目链接：<a href="https://leetcode.cn/problems/valid-parenthesis-string/" rel="nofollow">https://leetcode.cn/problems/valid-parenthesis-string/</a></p> <br><p>给你一个只包含三种字符的字符串，支持的字符类型分别是 <code>'('</code>、<code>')'</code> 和 <code>'*'</code>。请你检验这个字符串是否为有效字符串，如果是 <strong>有效</strong> 字符串返回 <code>true</code> 。</p> <br><p><strong>有效</strong> 字符串符合如下规则：</p> <br><ul><li>任何左括号 <code>'('</code> 必须有相应的右括号 <code>')'</code>。</li><li>任何右括号 <code>')'</code> 必须有相应的左括号 <code>'('</code> 。</li><li>左括号 <code>'('</code> 必须在对应的右括号之前 <code>')'</code>。</li><li><code>'*'</code> 可以被视为单个右括号 <code>')'</code> ，或单个左括号 <code>'('</code> ，或一个空字符串 <code>""</code>。</li></ul> <br><p> </p> <br><p><strong class="example">示例 1：</strong></p> <br><pre><strong>输入：</strong>s = "()"<br><strong>输出：</strong>true<br></pre> <br><p><strong class="example">示例 2：</strong></p> <br><pre><strong>输入：</strong>s = "(*)"<br><strong>输出：</strong>true<br></pre> <br><p><strong class="example">示例 3：</strong></p> <br><pre><strong>输入：</strong>s = "(*))"<br><strong>输出：</strong>true<br></pre> <br><p> </p> <br><p><strong>提示：</strong></p> <br><ul><li><code>1 <= s.length <= 100</code></li><li><code>s[i]</code> 为 <code>'('</code>、<code>')'</code> 或 <code>'*'</code></li></ul> <br><h3><a id="_51"></a>解题方法：一次遍历</h3> <br><p>使用两个变量<code>mx</code>和<code>mn</code>分别表示遍历到当前字符为止，左括号比右括号最多多几个、最少多几个。</p> <br><ul><li>遇到<code>(</code>则左括号必须比右括号多一个（<code>mx++, mn++</code>）</li><li>遇到<code>)</code>则左括号必须比右括号少一个（<code>mx--, mn--</code>）</li><li>遇到<code>*</code>时候<code>*</code>可以变成左括号（<code>mx++</code>），可以变成右括号（<code>mn--</code>），也可以变成空字符</li></ul> <br><p>一旦左括号比右括号最多多负数个（说明不论怎样左括号都比右括号少了）则立刻返回<code>false</code>；如果<code>mn == 0</code>则不再将<code>mn - 1</code>，因为要保证左括号始终<code>≥</code>右括号，二者数量相等的时候<code>*</code>不能变成<code>)</code>。</p> <br><p>最终，如果<code>mn == 0</code>则说明左括号比右括号最少多0个，说明可以通过将<code>*</code>变成<code>)</code>来使得左右括号数量相等。</p> <br><ul><li>时间复杂度<span class="katex--inline"><span class="katex"><span class="katex-mathml"><br>     <br>      <br>

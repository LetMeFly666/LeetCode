<h2><a id="MacOSOptionCommand_3"></a>MacOS：首次外接键盘初始化设置（Option/Command互换、左上角·～而非§±）</h2> <br><h3><a id="_5"></a>背景</h3> <br><p>Mac连接外接键盘可能会遇到以下情况：</p> <br><ul><li>Mac首次连接外接键盘可能会弹出“键盘设置助理”初始化设置，怎么设置？设置错了怎么办？（Esc下面的键按出来是<code>§±</code>而不是<code>~` </code>）</li><li>一些键盘不支持Mac模式（导致从左到右是<code>Ctrl、Command/Win、Alt/Option</code>而非<code>Ctrl、Option、Command</code>）</li></ul> <br><p><img src="https://i-blog.csdnimg.cn/direct/c8164caea1764061869d758085ab3e24.png" alt="键盘设置助理" /></p> <br><h3><a id="__14"></a>把<code>§±</code>设置成<code>~` </code></h3> <br><p>这个需要了解ANSI键和ISO键。如图红色部分是二者的区别：</p> <br><p><img src="https://i-blog.csdnimg.cn/direct/dbacdb6f15a447c1a9f0b2d0d9f55c8f.png" alt="ANSI和ISO键盘对比图，图源：https://www.typing-fingers.com/zh-TW/keyboard-layout-standards-ansi-vs-iso/" /></p> <br> <br><p>可以发现ISO键盘左边shift键的右边不是z，这也就是为什么刚连接键盘时候Mac让你按下左边shift右边的那个按键。</p> <br><p>以及，Tab键上面（1的左边）在ISO键盘中含义是<code>§±</code>，而不是现在常用的<code>~` </code>。</p> <br><p>如果你把你的键盘错选成了ISO，那么你想打<code>~` </code>则会得到<code>§±</code>。解决方案是重新运行一次“键盘设置助理”，把键盘设置为ANSI键盘。</p> <br><p>以MacOS26.5.2为例，“键盘设置助理”的位置是<code>左上角 -> 系统设置 -> 键盘 -> 更改键盘类型</code>：</p> <br><p><img src="https://i-blog.csdnimg.cn/direct/b7dd7744ca994519bbd568e23ee3d3eb.png" alt="“键盘设置助理”的位置是" /></p> <br><p>弹出“键盘设置助理”后点击<code>继续</code>、<code>Z</code>、<code>/</code>，选择<code>ANSI（美国）</code>、<code>完成</code>，可能需要重新拔插一下键盘，再次按下<code>1</code>左边打按钮就可以打出<code>~` </code>了。</p> <br><h3><a id="CtrlCommandWinAltOptionCtrlOptionCommand_33"></a>把<code>Ctrl、Command/Win、Alt/Option</code>设置为<code>Ctrl、Option、Command</code></h3> <br><p>这个需要在Mac里面更改一下<code>修饰键</code>，位置是<code>左上角 -> 系统设置 -> 键盘 -> 键盘快捷键 -> 修饰键</code></p> <br><p><img src="https://i-blog.csdnimg.cn/direct/943c56e5aba84aad8220c48a5a19b5d9.png" alt="左上角 -> 系统设置 -> 键盘 -> 键盘快捷键" /></p> <br><p>选择你的外接键盘，替换Command和Option两个修饰键即可。</p> <br><p><img src="https://i-blog.csdnimg.cn/direct/6b32e8591e824515839e9cbbe803fd8f.png" alt="更换Command和Option修饰键" /></p> <br><p>这样你按下键盘上的<code>Alt</code>就会得到<code>Command</code>一样的效果了。</p> <br><h3><a

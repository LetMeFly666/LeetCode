<h2><a id="LetMeFly1345_IVBFS_1"></a>【LetMeFly】1345.跳跃游戏 IV：广度优先搜索(BFS)</h2> <br><p>力扣题目链接：<a href="https://leetcode.cn/problems/jump-game-iv/" rel="nofollow">https://leetcode.cn/problems/jump-game-iv/</a></p> <br><p>给你一个整数数组 <code>arr</code> ，你一开始在数组的第一个元素处（下标为 0）。</p> <br><p>每一步，你可以从下标 <code>i</code> 跳到下标 <code>i + 1</code> 、<code>i - 1</code> 或者 <code>j</code> ：</p> <br><ul><li><code>i + 1</code> 需满足：<code>i + 1 < arr.length</code></li><li><code>i - 1</code> 需满足：<code>i - 1 >= 0</code></li><li><code>j</code> 需满足：<code>arr[i] == arr[j]</code> 且 <code>i != j</code></li></ul> <br><p>请你返回到达数组最后一个元素的下标处所需的 <strong>最少操作次数</strong> 。</p> <br><p>注意：任何时候你都不能跳到数组外面。</p> <br><p> </p> <br><p><strong>示例 1：</strong></p> <br><pre><strong>输入：</strong>arr = [100,-23,-23,404,100,23,23,23,3,404]<br><strong>输出：</strong>3<br><strong>解释：</strong>那你需要跳跃 3 次，下标依次为 0 --> 4 --> 3 --> 9 。下标 9 为数组的最后一个元素的下标。<br></pre> <br><p><strong>示例 2：</strong></p> <br><pre><strong>输入：</strong>arr = [7]<br><strong>输出：</strong>0<br><strong>解释：</strong>一开始就在最后一个元素处，所以你不需要跳跃。<br></pre> <br><p><strong>示例 3：</strong></p> <br><pre><strong>输入：</strong>arr = [7,6,9,6,9,6,9,7]<br><strong>输出：</strong>1<br><strong>解释：</strong>你可以直接从下标 0 处跳到下标 7 处，也就是数组的最后一个元素处。<br></pre> <br><p> </p> <br><p><strong>提示：</strong></p> <br><ul><li><code>1 <= arr.length <= 5 * 10<sup>4</sup></code></li><li><code>-10<sup>8</sup> <= arr[i] <= 10<sup>8</sup></code></li></ul> <br><h3><a id="BFS_57"></a>解题方法：广度优先搜索(BFS)</h3>

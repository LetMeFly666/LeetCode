<h2><a id="LetMeFly11111111_1"></a>【LetMeFly】1111.有效括号的嵌套深度：依据深度奇偶性分组（1111的题号果然参与的人多）</h2> <br><p>力扣题目链接：<a href="https://leetcode.cn/problems/maximum-nesting-depth-of-two-valid-parentheses-strings/" rel="nofollow">https://leetcode.cn/problems/maximum-nesting-depth-of-two-valid-parentheses-strings/</a></p> <br><p>如果一个字符串仅由字符 <code>"("</code> 和 <code>")"</code> 组成，并且满足以下条件，则称为有效括号字符串（VPS）：</p> <br><ul><li>它是空字符串，或</li><li>它可以表示为 <code>AB</code>（<code>A</code> 连接 <code>B</code>），其中 <code>A</code> 和 <code>B</code> 都是VPS，或者</li><li>它可以表示为 <code>(A)</code>，其中 <code>A</code> 是一个 VPS。</li></ul> <br><p>我们可以类似地定义任何 VPS <code>S</code> 的嵌套深度 <code>depth(S)</code> 如下：</p> <br><ul><li><code>depth("") = 0</code></li><li><code>depth(A + B) = max(depth(A), depth(B))</code>，其中 <code>A</code> 和 <code>B</code> 都是 VPS</li><li><code>depth("(" + A + ")") = 1 + depth(A)</code>，其中 <code>A</code> 是一个 VPS。</li></ul> <br><p>例如，<code>""</code>，<code>"()()"</code> 和 <code>"()(()())"</code> 都是 VPS（嵌套深度 0，1 和 2），并且 <code>")("</code> 和 <code>"(()"</code> 不是 VPS。</p> <br><p>给定一个 VPS 序列，将其拆分成两个不相交的子序列 <code>A</code> 和 <code>B</code>，使得 <code>A</code> 和 <code>B</code> 都是 VPS（且 <code>A.length + B.length = seq.length</code>）。这些子序列不一定是连续的。</p> <br><p>例如，对于序列 <code>123456789</code>，一种可能的拆分是：</p> <br><ul><li> <p><code>A = {1, 3, 5, 7, 9}</code>，</p> </li><li> <p><code>B = {2, 4, 6, 8}</code>。</p> </li><li> <p>这对应于输出 <code>[0, 1, 0, 1, 0, 1, 0, 1, 0]</code>，其中 0 表示属于 <code>A</code>，1 表示属于 <code>B</code>。</p> </li></ul> <br><p>现在选择 <strong>任意</strong> 这样的 <code>A</code> 和 <code>B</code>，使得 <code>max(depth(A), depth(B))</code> 的值是最小的。</p> <br><p>返回一个 <code>answer</code> 数组（长度为 <code>seq.length</code>），该数组编码了 <code>A</code> 和 <code>B</code> 的选择：如果 <code>seq[i]</code> 是 <code>A</code> 的一部分则 <code>answer[i] = 0</code>，否则 <code>answer[i] = 1</code>。请注意，尽管可能存在多种答案，但你可以返回其中任意一种。</p> <br><p> </p> <br><p><strong>示例 1：</strong></p> <br><pre><strong>输入：</strong>seq = "(()())"<br><strong>输出：</strong>[0,1,1,1,1,0]<br></pre> <br><p><strong>示例 2：</strong></p> <br><pre><strong>输入：</strong>seq = "()(())()"<br><strong>输出：</strong>[0,0,0,1,1,0,1,1]<br><strong>解释：</strong>本示例答案不唯一。<br>按此输出 A = "()()", B = "()()", max(depth(A), depth(B)) = 1，它们的深度最小。<br>像 [1,1,1,0,0,1,1,1]，也是正确结果，其中 A = "()()()", B = "()", max(depth(A), depth(B)) = 1 。 <br></pre> <br><p> </p> <br><p><strong>提示：</strong></p> <br><ul><li><code>1 < seq.size <= 10000</code></li></ul> <br><p> </p> <br><p><strong>有效括号字符串：</strong></p> <br><pre>仅由 <code>"("</code> 和 <code>")"</code> 构成的字符串，对于每个左括号，都能找到与之对应的右括号，反之亦然。<br>下述几种情况同样属于有效括号字符串：<br><br>  1. 空字符串<br>  2. 连接，可以记作 <code>AB</code>（<code>A</code> 与 <code>B</code> 连接），其中 <code>A</code> 和 <code>B</code> 都是有效括号字符串<br>  3. 嵌套，可以记作 <code>(A)</code>，其中 <code>A</code> 是有效括号字符串<br></pre> <br><p><strong>嵌套深度：</strong></p> <br><pre>类似地，我们可以定义任意有效括号字符串 <code>s</code> 的 <strong>嵌套深度</strong> <code>depth(S)</code>：<br><br>  1.<code> s</code> 为空时，<code>depth("") = 0</code><br><code>  2. s</code> 为 <code>A</code> 与 <code>B</code> 连接时，<code>depth(A + B) = max(depth(A), depth(B))</code>，其中 <code>A</code> 和 <code>B</code> 都是有效括号字符串<br><code>  3. s</code> 为嵌套情况，<code>depth("(" + A + ")") = 1 + depth(A)</code>，其中 <code>A</code> 是有效括号字符串<br><br>例如：<code>""</code>，<code>"()()"</code>，和 <code>"()(()())"</code> 都是有效括号字符串，嵌套深度分别为 0，1，2，而 <code>")("</code> 和 <code>"(()"</code> 都不是有效括号字符串。<br></pre> <br><h3><a id="_97"></a>解题方法：依据奇偶性分组</h3> <br><p>使用一个变量<code>layer</code>记录当前括号的嵌套深度，遇到<code>(</code>则<code>layer</code>加1，遇到<code>)</code>则<code>layer</code>减1。</p> <br><p>奇数<code>layer</code>的括号分<code>A</code>组，偶数<code>layer</code>的括号分<code>B</code>组。</p> <br><p>然后你可能就会发现<code>Wrong Answer</code>了。</p> <br><p>这是因为，遇到<code>(</code>时需要先将嵌套深度<code>layer</code>加一再判奇偶，而遇到<code>)</code>时先别急着给人家的深度减一，判完奇偶再减一。</p> <br><ul><li>时间复杂度<span class="katex--inline"><span class="katex"><span

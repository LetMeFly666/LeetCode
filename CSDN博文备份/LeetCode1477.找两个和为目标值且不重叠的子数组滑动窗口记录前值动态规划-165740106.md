<h2><a id="LetMeFly1477___1"></a>【LetMeFly】1477.找两个和为目标值且不重叠的子数组：滑动窗口 + 记录前值(动态规划)</h2> <br><p>力扣题目链接：<a href="https://leetcode.cn/problems/find-two-non-overlapping-sub-arrays-each-with-target-sum/" rel="nofollow">https://leetcode.cn/problems/find-two-non-overlapping-sub-arrays-each-with-target-sum/</a></p> <br><p>给你一个整数数组 <code>arr</code> 和一个整数值 <code>target</code> 。</p> <br><p>请你在 <code>arr</code> 中找 <strong>两个互不重叠的子数组</strong> 且它们的和都等于 <code>target</code> 。可能会有多种方案，请你返回满足要求的两个子数组长度和的 <strong>最小值</strong> 。</p> <br><p>请返回满足要求的最小长度和，如果无法找到这样的两个子数组，请返回 <strong>-1</strong> 。</p> <br><p> </p> <br><p><strong>示例 1：</strong></p> <br><pre><strong>输入：</strong>arr = [3,2,2,4,3], target = 3<br><strong>输出：</strong>2<br><strong>解释：</strong>只有两个子数组和为 3 （[3] 和 [3]）。它们的长度和为 2 。<br></pre> <br><p><strong>示例 2：</strong></p> <br><pre><strong>输入：</strong>arr = [7,3,4,7], target = 7<br><strong>输出：</strong>2<br><strong>解释：</strong>尽管我们有 3 个互不重叠的子数组和为 7 （[7], [3,4] 和 [7]），但我们会选择第一个和第三个子数组，因为它们的长度和 2 是最小值。<br></pre> <br><p><strong>示例 3：</strong></p> <br><pre><strong>输入：</strong>arr = [4,3,2,6,2,3,4], target = 6<br><strong>输出：</strong>-1<br><strong>解释：</strong>我们只有一个和为 6 的子数组。<br></pre> <br><p><strong>示例 4：</strong></p> <br><pre><strong>输入：</strong>arr = [5,5,4,4,5], target = 3<br><strong>输出：</strong>-1<br><strong>解释：</strong>我们无法找到和为 3 的子数组。<br></pre> <br><p><strong>示例 5：</strong></p> <br><pre><strong>输入：</strong>arr = [3,1,1,1,5,1,2,1], target = 3<br><strong>输出：</strong>3<br><strong>解释：</strong>注意子数组 [1,2] 和 [2,1] 不能成为一个方案因为它们重叠了。<br></pre> <br><p> </p> <br><p><strong>提示：</strong></p> <br><ul><li><code>1 <= arr.length <= 10^5</code></li><li><code>1 <= arr[i] <= 1000</code></li><li><code>1 <= target <= 10^8</code></li></ul> <br><h3><a id="_60"></a>解题方法：滑动窗口</h3> <br><p>如果这道题只需要求一个和为<code>target</code>的最短子数组的长度，那么一个滑动窗口就可以解决：</p> <br><blockquote> <br> <p>用两个指针<code>l</code>和<code>r</code>表示滑动窗口的左右边界，用变量<code>cnt</code>表示当前窗口内元素的和。</p> <br> <p>每次右指针<code>r</code>右移一位，当<code>cnt > target</code>时，不断右移左指针。如果<code>cnt == target</code>，则更新最短子数组的长度。</p> <br></blockquote> <br><p>现在变成了两个和为<code>target</code>的不重叠子数组，怎么办？也好办，用一个数组把

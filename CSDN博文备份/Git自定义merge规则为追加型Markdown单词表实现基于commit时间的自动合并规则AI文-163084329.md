<h2><a id="Gitmerge_Markdown__commit_AI_1"></a>Git：自定义merge规则——为追加型 Markdown 单词表实现基于 commit 时间的自动合并规则（AI文）</h2> <br><blockquote> <br> <p>本文总结<a href="https://chatgpt.com/c/6a5f8435-2988-83ea-a577-bf2dc843e881" rel="nofollow">自</a>ChatGPT！ <a href="https://chatgpt.com/share/6a60c2de-7a4c-83ea-9e07-147aed3d92e3" rel="nofollow">某分支的ChatLink</a></p> <br></blockquote> <br><h3><a id="_6"></a>背景</h3> <br><blockquote> <br> <p>Git<br /> 默认的三方合并适合处理普通文本修改，但对于追加型日志文件（例如单词学习记录），更适合使用基于<br /> commit history 的自定义 merge driver。</p> <br></blockquote> <br><p>要解决的问题：</p> <br><p>仓库中有一个 Markdown 文件：</p> <br><pre><code>Solutions/Other-English-LearningNotes-SomeWords.md<br></code></pre> <br><p>该文件包含：</p> <br><ul><li>Markdown 元信息</li><li>一个长期追加的单词表</li><li>后续其他笔记内容</li></ul> <br><p>单词表类似：</p> <br><pre><code>|corrosion|n. 腐蚀；锈蚀|<br>|fragrant|adj. 香的|<br>|||<br>|magnetism|n. 磁性，吸引力/魅力|<br></code></pre> <br><p>其中：</p> <br><pre><code>|||<br></code></pre> <br><p>表示一次新的背单词记录。</p> <br><p>由于该文件只追加，不应该使用普通文本 merge。</p> <br><p>例如：</p> <br><p>分支 A：</p> <br><pre><code>|||<br>|1||<br></code></pre> <br><p>分支 B：</p> <br><pre><code>|||<br>||2|<br></code></pre> <br><p>正确结果应该按照 commit 时间：</p> <br><pre><code>|||<br>|1||<br>|||<br>||2|<br></code></pre> <br><p>而不是依赖 Git 默认 diff merge。</p> <br><hr /> <br><h3><a id="_63"></a>技术原理</h3> <br><h4><a id="Git_merge_driver_65"></a>Git merge driver</h4> <br><p>Git 支持针对特定文件指定 merge driver。</p> <br><p><code>.gitattributes</code>：</p> <br><pre><code>Solutions/Other-English-LearningNotes-SomeWords.md merge=words<br></code></pre> <br><p><code>.git/config</code>：</p> <br><pre><code class="prism language-ini">[merge "words"]<br>    name = English words timestamp merge<br>    driver = python3 merge_words.py %O %A %B<br></code></pre> <br><p>参数：</p> <br><p>参数 含义</p> <br><hr /> <br><p>%O 共同祖先文件<br /> %A 当前 merge 结果文件<br /> %B

<br><ul><li>launch.json</li><li>setupCommands</li><li>~/.gdbinit</li></ul> <br><p>都发生得太晚。</p> <br><hr /> <br><h2><a id="_652"></a>最终状态</h2> <br><p>现在系统行为：</p> <br><pre><code class="prism <br><h2><a id="_696"></a>经验总结</h2> <br><h3><a id="1_Downloading_xxx_MB__698"></a>1. <code>Downloading xxx MB</code> 不等于下载成功</h3> <br><p>只是 server 告诉你：</p> <br><pre><code class="prism language-text">这个文件大小是 xxx MB<br></code></pre> <br><hr /> <br><h3><a id="2_debuginfo__708"></a>2. debuginfo 不是运行库</h3> <br><pre><code class="prism language-text">libstdc++.so<br></code></pre> <br><p>只是 runtime。</p> <br><p>真正大的：</p> <br><pre><code class="prism language-text">DWARF debug symbols<br></code></pre> <br><hr /> <br><h3><a id="3_debuginfod__724"></a>3. debuginfod 是增强功能，不是必须</h3> <br><p>没有它：</p> <br><p>普通 C++ debug 仍然完全可用。</p> <br><hr /> <br><h3><a id="4_GDB__732"></a>4.

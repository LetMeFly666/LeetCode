<br><ul><li><code>max(nums[0..i])</code> 表示从下标 0 到下标 <code>i</code> 的元素中的<strong> 最大值</strong> 。</li><li><code>min(nums[i..n - 1])</code> 表示从下标 <code>i</code> 到下标 <code>n - 1</code> 的元素中的 <strong>最小值 </strong>。</li></ul> <br><p>如果某个下标 <code>i</code> 的不稳定值<strong> 小于等于</strong> <code>k</code>，则称该下标为 <strong>稳定下标</strong> 。</p> <br><p>返回 <strong>最小 </strong>的稳定下标。如果不存在这样的下标，则返回 <code>-1</code>。</p> <br><p> </p> <br><p><strong class="example">示例 1：</strong></p> <br><div class="example-block"> <br> <p><strong>输入：</strong> <span class="example-io">nums = [5,0,1,4], k = 3</span></p> <br></div><br><p><strong>输出：</strong> <span class="example-io">3</span></p> <br><p><strong>解释：</strong></p> <br><ul><li>在下标 0 处：<code>[5]</code> 中的最大值是 5，<code>[5, 0, 1, 4]</code> 中的最小值是 0，因此不稳定值为 <code>5 - 0 = 5</code>。</li><li>在下标 1 处：<code>[5, 0]</code> 中的最大值是 5，<code>[0, 1, 4]</code> 中的最小值是 0，因此不稳定值为 <code>5 - 0 = 5</code>。</li><li>在下标 2 处：<code>[5, 0, 1]</code> 中的最大值是 5，<code>[1, 4]</code> 中的最小值是 1，因此不稳定值为 <code>5 - 1 = 4</code>。</li><li>在下标 3 处：<code>[5, 0, 1, 4]</code> 中的最大值是 5，<code>[4]</code> 中的最小值是 4，因此不稳定值为 <code>5 - 4 = 1</code>。</li><li>这是第一个不稳定值小于等于 <code>k = 3</code> 的下标，因此答案是 3。</li></ul> <br><p><strong class="example">示例 2：</strong></p> <br><div class="example-block"> <br> <p><strong>输入：</strong> <span class="example-io">nums = [3,2,1], k = 1</span></p> <br></div><br><p><strong>输出：</strong> <span class="example-io">-1</span></p> <br><p><strong>解释：</strong></p> <br><ul><li>在下标 0 处，不稳定值为 <code>3 - 1 = 2</code>。</li><li>在下标 1 处，不稳定值为 <code>3 - 1 = 2</code>。</li><li>在下标 2 处，不稳定值为 <code>3 - 1 = 2</code>。</li><li>这些值都不小于等于 <code>k = 1</code>，因此答案是 <code>-1</code>。</li></ul> <br><p><strong class="example">示例 3：</strong></p> <br><div <br><p><strong>解释：</strong></p> <br><p>在下标 0 处，不稳定值为 <code>0 - 0 = 0</code>，它小于等于 <code>k = 0</code>。因此答案是 0。</p> <br><p> </p> <br><p><strong>提示：</strong></p> <br><ul><li><code>1 <= nums.length <=

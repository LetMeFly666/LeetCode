<h2><a id="VsCode_markdown_1"></a>在VsCode markdown的公式中快速插入⌊分数⌋等代码段</h2> <br><h3><a id="_3"></a>背景</h3> <br><p>在markdown中写题解的时候经常会需要在LaTeX公式中输入类似<code>$\lfloor\frac{x}{2}\rfloor$</code>这样的代码，但是(对于坚持手写题解的<em>大佬</em>来说)这一长串手打起来还挺慢的。好在VsCode支持<em>代码片段</em>，在特定文件输入特定前缀可以插入指定代码，并且还能自定义光标位置、按tab切到下一个光标位置。</p> <br><p><strong>分享这种操作的文章不是很多么？这篇文章的意义是什么？</strong></p> <br><p>笔者在N年前就在VsCode上配置了一些cpp的代码段，这两天突然想起了配置markdown的代码段，结果发现需要解决以下问题才能配置成功：</p> <br><ul><li>markdown默认没有补全提示</li><li>markdown中即使配置了代码段，也无法在输入了<code>$</code>后的公式中补全</li><li>大模型也无法直接给出这个问题的准确答案</li></ul> <br><p>先来个最终效果：</p> <br><p><img src="https://i-blog.csdnimg.cn/direct/589548de8ba9436390bb8d524b14068b.gif" alt="向下取整：" /></p> <br><p>VsCode中输入<code>分数</code>的拼音<code>fenshu</code>可以插入<code>\lfloor\frac{}{2}\rfloor</code>代码段，光标默认定位到分子，按tab键定位到分母，分母默认是<span class="katex--inline"><span class="katex"><span class="katex-mathml"> <br>     <br>      <br>       <br>       <br>         2 <br>        <br>       <br>      <br>        2 <br>       <br>      <br>    </span><span class="katex-html"><span class="base"><span class="strut" style="height: 0.6444em;"></span><span class="mord">2</span></span></span></span></span>，再按Tab键定位到向下取整分数的结尾。</p> <br><h3><a id="_21"></a>设置</h3> <br><h4><a id="_23"></a>新增代码段</h4> <br><p><code>Cmd/Ctrl + Shift + P -> Snippets: Configure Snippets -> 新建全局代码片段文件</code></p> <br><p>注意(01)，一定要新建<strong>全局</strong>代码片段文件，不可以只选中markdown文件类型。因为输入 <code>⌊分数⌋</code> 的时候都是在markdown的公式中输入的，如果你新建一个关于markdown文件的代码段，很抱歉，你输入了<code>$</code>并开始输入<code>fenshu</code>的时候，诶，VsCode认为你在输入LaTeX，不给你弹代码段哈哈。</p> <br><p>如果你想限制代码段的生效范围是<code>markdown</code>和<code>LaTeX</code>，可以在全局代码段文件中新增<code>"scope": "markdown,latex"</code>配置（如果你选中markdown代码段的话，是不支持scope字段的）。</p> <br><p>删掉默认的字符，把下面的字符粘贴进去（并保存）：</p> <br><pre><code class="prism language-json"><span class="token punctuation">{<!-- --></span><br>	<span class="token string-property property">"LaTeX Floor Fraction"</span><span class="token operator">:</span> <span class="token punctuation">{<!-- --></span><br>		<span class="token string-property property">"scope"</span><span class="token operator">:</span> <span class="token string">"markdown,latex"</span><span class="token punctuation">,</span><br>        <span class="token string-property property">"prefix"</span><span class="token operator">:</span> <span class="token string">"fenshu"</span><span class="token punctuation">,</span><br>        <span class="token string-property property">"body"</span><span class="token operator">:</span> <span class="token punctuation">[</span><br>            <span class="token string">"\\\\lfloor\\\\frac{$1}{${2:2}}\\\\rfloor"</span><br>        <span class="token punctuation">]</span><span class="token punctuation">,</span><br>        <span class="token string-property property">"description"</span><span class="token operator">:</span> <span class="token string">"LaTeX中分数并向下取整"</span><br>    <span class="token punctuation">}</span><span class="token punctuation">,</span><br><span class="token punctuation">}</span><br></code></pre> <br><p>注意(02)这里面<code>\</code>的转义，<code>\frac</code>要写成<code>\\\\frac</code>，因为：</p> <br><ul><li>JSON 解析一次：<code>\\\\</code> → <code>\\</code></li><li>snippet 插入时：<code>\\</code> → <code>\</code></li></ul> <br><h4><a id="markdown_51"></a>开启markdown文件的自动补全</h4> <br><p>不知道你的VsCode默认配置是怎样的，设置好上面的代码段后，你可能迫不及待地在markdown中尝试，但是发现怎么都触发不了自动补全提示。</p> <br><h5><a id="_55"></a>插件</h5> <br><p>这可能是因为你的VsCode对于markdown文件的补全建议默认是关闭的。这可能是插件所致(03)，测试方式是<code>Cmd/Ctrl + Shift + P -> Developer: Reload with Extensions Disabled</code>，看下是否会自动补全。(大概率会)如果还不能自动补全，说明不是插件所致。</p> <br><p>置于关闭<em>不含插件的重新启动</em>的方式不用担心，你关闭插件并重启后，右下角会有一个很明显的提示，说这次启动禁用了所有插件，点击按钮正常重新加载VsCode。</p> <br><h5><a id="_62"></a>配置</h5> <br><p>你可以通过在<code>settings.json</code>中新增如下配置来实现VS Code针对markdown的补全建议(04)：</p> <br><pre><code class="prism language-json">    <span class="token string-property property">"[markdown]"</span><span class="token operator">:</span> <span class="token punctuation">{<!-- --></span>  <span class="token comment">// 不然markdown没有补全</span><br>        <span class="token string-property property">"editor.quickSuggestions"</span><span class="token operator">:</span> <span class="token punctuation">{<!-- --></span><br>            <span class="token comment">// 官方文档中只找到了这三个控制粒度，其中other必须设置为true</span><br>            <span class="token string-property property">"other"</span><span class="token operator">:</span> <span class="token boolean">true</span><span class="token punctuation">,</span><br>            <span class="token comment">// "comments": true,</span><br>            <span class="token comment">// "strings": true,</span><br>        <span class="token punctuation">}</span><span class="token punctuation">,</span><br>    <span class="token punctuation">}</span><span class="token punctuation">,</span><br></code></pre> <br><p>这个<code>settings.json</code>打开方式是<code>Cmd/Ctrl + Shift + P -> Preferences: Open User Settings (JSON)</code>。</p> <br><p>至此，你就可以愉快地使用了。</p> <br><blockquote> <br> <p>其他公式(原理类似)，以后再来探索吧。</p> <br></blockquote> <br><h2><a id="End_83"></a>End</h2> <br><ul><li>

<h2><a id="VsCode__Cipch_1"></a>VsCode缓存清理 - 限制C++拓展的缓存文件ipch空间占用</h2> <br><p>前文《<a href="https://blog.letmefly.xyz/2022/07/30/Other-VsCode-WhyLightweightVsCodeCanEatMyCDrive10G/" rel="nofollow">VsCode缓存清理 - 轻量级的VsCode为何越用越大？为什么吃了我C盘10G？如何无痛清理VsCode缓存？手把手教你为C盘瘦身</a>》通过Windows上的bat脚本实现了VsCode缓存的清理，可以释放大量空间。但是使用一段时间后空间占用还会逐渐增大。如果你是C++用户，那么也许你需要关注一下本篇文章。</p> <br><h3><a id="_5"></a>缓存文件介绍</h3> <br><p><code>ipch</code> 是 Microsoft C/C++ 扩展用于 IntelliSense 的缓存目录，主要用于缓存预编译头（Precompiled Header）等 IntelliSense 数据。</p> <br><p>默认情况下，Windows 存放在 <code>%LocalAppData%\Microsoft\vscode-cpptools</code>，即<code>C:\Users\<用户名>\AppData\Local\Microsoft\vscode-cpptools</code>。</p> <br><p>其中包含：</p> <br><ol><li> <p>数个数字和字母组成的哈希文件夹，每个几十M，想删就删（特别是不只有一个这样的文件夹的时候），下次还会自动生成。</p> <p>这个文件无法通过配置设置存放位置、大小，但好在空间占用不算大。</p> </li><li> <p>ipch文件夹。</p> <p>里面有很多数字和字母组成的哈希文件夹，哈希为cpp源文件的路径映射，每个cpp文件对应一个哈希文件夹。</p> <p>ipch文件夹默认总大小为5G。对于某些C盘吃紧的老设备还是有点挑战的。</p> </li></ol> <br><h3><a id="_22"></a>缓存配置</h3> <br><p>可以在<code>settings.json</code>（打开方式可以为<code>Ctrl + Shift + P -> Preferences: Open User settings (JSON)</code>）中新增如下配置：</p> <br><pre><code class="prism language-json"><span class="token string-property property">"C_Cpp.intelliSenseCachePath"</span><span class="token operator">:</span> <span class="token string">"F:\\FromC\\VsCode\\ipch"</span><span class="token punctuation">,</span><br><span class="token string-property property">"C_Cpp.intelliSenseCacheSize"</span><span class="token operator">:</span> <span class="token number">4096</span><span class="token punctuation">,</span><br><span class="token string-property property">"settingsSync.ignoredSettings"</span><span class="token operator">:</span> <span class="token punctuation">[</span><br>    <span class="token string">"-C_Cpp.intelliSenseCachePath"</span><br><span class="token punctuation">]</span><span class="token punctuation">,</span><br></code></pre> <br><p>第一个<code>C_CPP.intelliSenseCachePath</code>配置为<code>ipch</code>缓存文件存放路径，第二个<code>C_Cpp.intelliSenseCacheSize</code>配置为<code>ipch</code>缓存文件最大占用空间（单位为MB）。</p> <br><p>第三个<code>settingsSync.ignoredSettings</code>是配置哪些配置不跨设备同步，由于缓存路径位置在不同电脑上可能不同，所以这里我设置ipch缓存位置不随设备同步，这样在其他设备登录VsCode账号，会同步其他配置而不同步这个，就可以实现每个设备配置不同的ipch缓存位置了。</p> <br><p>当配置路径不存在时会存放到默认位置。</p>

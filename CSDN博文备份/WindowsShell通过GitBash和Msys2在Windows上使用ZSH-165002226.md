<h2><a id="WindowsShell__Git_BashMsys2WindowsZSH_1"></a>Windows(Shell) —— 通过Git Bash和Msys2在Windows上使用ZSH</h2> <br><blockquote> <br> <p>天下人苦cmd久矣(bushi)</p> <br></blockquote> <br><p>Windows自带的cmd和PowerShell在使用上都不如Linux下的shell方便，安装了Git后默认会带有Git Bash（运行时基于msys2-runtime修改而来），只需要再安装一个MSYS2的zsh就能在Windows上通过Git Bash使用zsh了。</p> <br><h3><a id="Git__7"></a>Git 安装（简述）</h3> <br><p>折腾Windows上ZSH的大概都安装过git。如果没，那就在<a href="https://git-scm.com/install/windows" rel="nofollow">官网</a><a href="https://github.com/git-for-windows/git/releases/download/v2.55.0.windows.5/Git-2.55.0.5-64-bit.exe">下载</a>并安装即可。</p> <br><p>安装完成后如果你能正常使用<code>git</code>命令那么你大概率也可以直接使用<code>bash</code>命令来使用Git Bash了。</p> <br><h3><a id="MSYS2_13"></a>MSYS2简介</h3> <br><p>MSYS2是一个在Windows上运行的类Unix环境，如果你想要省事儿的话，也可以直接安装一个MSYS2。MSYS2使用<code>pacman</code>作为包管理器，可以直接使用<code>pacman -S zsh</code>来安装zsh。</p> <br><p>但这不是本文的目的。由于Git Bash本身就是基于msys2-runtime修改而来，所以我们可以直接在Git Bash中使用MSYS2的zsh。</p> <br><h3><a id="ZSH_19"></a>ZSH下载“安装”</h3> <br><p>访问<a href="https://packages.msys2.org/packages/zsh?repo=msys&variant=x86_64" rel="nofollow">msys2官网的zsh包</a>，找到<code>File:</code>后面的下载链接：<a href="https://mirror.msys2.org/msys/x86_64/zsh-5.9.2-1-x86_64.pkg.tar.zst" rel="nofollow">https://mirror.msys2.org/msys/x86_64/zsh-5.9.2-1-x86_64.pkg.tar.zst</a>，这是一个压缩包，可以使用Bandizip或者7-Zip等工具解压。</p> <br><p>解压后你可能会得到一个压缩包，再解压一次可得到一些文件（夹）：</p> <br><pre><code>zsh-5.9.2-1-x86_64.pkg<br>├─etc<br>│  └─zsh<br>└─usr<br>│   ├─bin<br>│   ├─lib<br>│   │  └─zsh<br>│   │      └─5.9.2<br>│   │          └─zsh<br>│   │              ├─net<br>│   │              └─param<br>│   └─share<br>│       ├─licenses<br>│       │  └─zsh<br>│       ├─man<br>│       │  └─man1<br>│       └─zsh<br>│           ├─5.9.2<br>│           │  └─help<br>│           ├─functions<br>│           │  ├─Calendar<br>│           │  ├─Chpwd<br>│           │  ├─Completion<br>│           │  │  ├─Base<br>│           │  │  ├─Linux<br>│           │  │  ├─Unix<br>│           │  │  ├─X<br>│           │  │  └─Zsh<br>│           │  ├─Exceptions<br>│           │  ├─Math<br>│           │  ├─MIME<br>│           │  ├─Misc<br>│           │  ├─Newuser<br>│           │  ├─Prompts<br>│           │  ├─TCP<br>│           │  ├─VCS_Info<br>│           │  │  └─Backends<br>│           │  ├─Zftp<br>│           │  └─Zle<br>│           ├─scripts<br>│           └─site-functions<br>├─.BUILDINFO<br>├─.INSTALL<br>├─.MTREE<br>└─.PKGINFO<br></code></pre> <br><p>其中<code>.</code>开头的4个文件不用管，只需要把<code>etc</code>和<code>usr</code>文件夹放到Git Bash的安装目录下就好了。</p> <br><p><code>Git Bash</code>的安装目录在哪里？可以这样找到：<code>Win + R</code>，输入<code>cmd</code>，在弹出的窗口中输入<code>where bash</code>，得到类似<code>C:\Program Files\Git\bin\bash.exe</code>的路径，那么<code>Git Bash</code>的安装目录就是<code>C:\Program Files\Git</code>。</p> <br><p>你看<code>C:\Program Files\Git</code>目录也有<code>etc</code>和<code>usr</code>文件夹，直接把解压后的<code>etc</code>和<code>usr</code>文件夹拖拽到这个目录下就可以了，会自动合并子文件夹（如果你不放心也可以手动递归复制文件(夹)到对应的目录）。</p> <br><p>现在你在<code>Git Bash</code>中输入<code>zsh</code>，应该会有如下提示，直接按<code>0</code>跳过就行：</p> <br><pre><code>This is the Z Shell configuration function for new users,<br>zsh-newuser-install.<br>You are seeing this message because you have no zsh startup files<br>(the files .zshenv, .zprofile, .zshrc, .zlogin in the directory<br>~). This function can help you with a few settings that should<br>make your use of the shell easier.<br><br>You can:<br><br>(q) Quit and do nothing. The function will be run again next time.<br><br>(0) Exit, creating the file ~/.zshrc containing just a comment.<br>That will prevent this function being run again.<br><br>(1) Continue to the main menu.<br><br>--- Type one of the keys in parentheses ---<br></code></pre> <br><p>关于怎么打开<code>Git bash</code>，如果你是下载的Git安装包一路安装的话，应该可以在任意目录下右键，选择“在Git Bash中打开”；如果没有类似选项，也可以<code>Win + R</code>输入<code>bash</code>并回车即可。</p> <br><h3><a id="ZSH_103"></a>ZSH的简单配置</h3> <br><h4><a id="git_bashzsh_105"></a>git bash默认使用zsh</h4> <br><p>先把你的输入法调成英文，然后在<code>Git Bash</code>中输入：</p> <br><pre><code class="prism language-bash"><span class="token function">vim</span> ~/.bashrc<br></code></pre> <br><p>按<code>i</code>进入编辑模式，粘贴如下内容：</p> <br><pre><code class="prism language-bash"><span class="token keyword">if</span> <span class="token punctuation">[</span> <span class="token parameter variable">-t</span> <span class="token number">1</span> <span class="token punctuation">]</span><span class="token punctuation">;</span> <span class="token keyword">then</span><br>  <span class="token builtin class-name">exec</span> <span class="token function">zsh</span><br><span class="token keyword">fi</span><br></code></pre> <br><p>按<code>Esc</code>退出编辑模式，输入<code>:wq</code>保存并退出。</p> <br><p>这段命令的意思如下：<code>[ -t 1 ]</code>表示判断“文件描述符 1（stdout 标准输出）是不是终端”，如果是在交互式终端中运行则条件成立，启动zsh并使用zsh替换当前shell进程，否则（例如重定向到文件等场景）条件不成立就不切到zsh了。</p> <br><p>也可以写成：</p> <br><pre><code class="prism language-bash"><span class="token keyword">if</span> <span class="token punctuation">[</span><span class="token punctuation">[</span> $- <span class="token operator">==</span> *i* <span class="token punctuation">]</span><span class="token punctuation">]</span><span class="token punctuation">;</span> <span class="token keyword">then</span><br>  <span class="token builtin class-name">exec</span> <span class="token function">zsh</span><br><span class="token keyword">fi</span><br></code></pre> <br><p><code>$-</code> 是 Bash 的一个特殊变量，里面放着当前 Shell 的各种运行选项。如果这个字符串里面有<code>i</code>（代表interactive）就说明是交互式终端。</p> <br><h4><a id="_135"></a>后续自定义配置</h4> <br><p>后面怎么配置就可以跟Linux和Mac上一样了，比如安装个<code>oh-my-zsh</code>和<code>zsh-autosuggestions</code>之类的。</p> <br><h3><a id="End_139"></a>End</h3> <br><p>参考文献：</p>

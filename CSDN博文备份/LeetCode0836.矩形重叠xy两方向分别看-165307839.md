<h2><a id="LetMeFly836xy_1"></a>【LetMeFly】836.矩形重叠：xy两方向分别看</h2> <br><p>力扣题目链接：<a href="https://leetcode.cn/problems/rectangle-overlap/" rel="nofollow">https://leetcode.cn/problems/rectangle-overlap/</a></p> <br><p>矩形以列表 <code>[x1, y1, x2, y2]</code> 的形式表示，其中 <code>(x1, y1)</code> 为左下角的坐标，<code>(x2, y2)</code> 是右上角的坐标。矩形的上下边平行于 x 轴，左右边平行于 y 轴。</p> <br><p>如果相交的面积为 <strong>正</strong> ，则称两矩形重叠。需要明确的是，只在角或边接触的两个矩形不构成重叠。</p> <br><p>给出两个矩形 <code>rec1</code> 和 <code>rec2</code> 。如果它们重叠，返回 <code>true</code>；否则，返回 <code>false</code> 。</p> <br><p> </p> <br><p><strong>示例 1：</strong></p> <br><pre><strong>输入：</strong>rec1 = [0,0,2,2], rec2 = [1,1,3,3]<br><strong>输出：</strong>true<br></pre> <br><p><strong>示例 2：</strong></p> <br><pre><strong>输入：</strong>rec1 = [0,0,1,1], rec2 = [1,0,2,1]<br><strong>输出：</strong>false<br></pre> <br><p><strong>示例 3：</strong></p> <br><pre><strong>输入：</strong>rec1 = [0,0,1,1], rec2 = [2,2,3,3]<br><strong>输出：</strong>false<br></pre> <br><p> </p> <br><p><strong>提示：</strong></p> <br><ul><li><code>rect1.length == 4</code></li><li><code>rect2.length == 4</code></li><li><code>-10<sup>9</sup> <= rec1[i], rec2[i] <= 10<sup>9</sup></code></li><li><code>rec1</code> 和 <code>rec2</code> 表示一个面积不为零的有效矩形</li></ul> <br><h3><a id="_47"></a>解题方法：线段相交</h3> <br><p>一维坐标系中一条线段从<code>la</code>到<code>ra</code>，另一条线段从<code>lb</code>到<code>rb</code>。假设<code>la <= ra</code>，那么什么情况下两条线段相交呢？答案是<code>lb < ra</code>。</p> <br><p>二维空间中，如果两个正方形在x轴方向上和y轴方向上线段都相交，则两正方形有重叠。</p> <br><ul><li>时间复杂度<span class="katex--inline"><span class="katex"><span class="katex-mathml"><br>     <br>      <br>       <br>        <br>

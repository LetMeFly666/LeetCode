<h2><a id="LetMeFly2948_1"></a>【LetMeFly】2948.交换得到字典序最小的数组：两层排序</h2> <br><p>力扣题目链接：<a href="https://leetcode.cn/problems/make-lexicographically-smallest-array-by-swapping-elements/" rel="nofollow">https://leetcode.cn/problems/make-lexicographically-smallest-array-by-swapping-elements/</a></p> <br><p>给你一个下标从 <strong>0 </strong>开始的 <strong>正整数</strong> 数组 <code>nums</code> 和一个 <strong>正整数</strong> <code>limit</code> 。</p> <br><p>在一次操作中，你可以选择任意两个下标 <code>i</code> 和 <code>j</code>，<strong>如果</strong> 满足 <code>|nums[i] - nums[j]| <= limit</code> ，则交换 <code>nums[i]</code> 和 <code>nums[j]</code> 。</p> <br><p>返回执行任意次操作后能得到的 <strong>字典序最小的数组</strong><em> </em>。</p> <br><p>如果在数组 <code>a</code> 和数组 <code>b</code> 第一个不同的位置上，数组 <code>a</code> 中的对应元素比数组 <code>b</code> 中的对应元素的字典序更小，则认为数组 <code>a</code> 就比数组 <code>b</code> 字典序更小。例如，数组 <code>[2,10,3]</code> 比数组 <code>[10,2,3]</code> 字典序更小，下标 <code>0</code> 处是两个数组第一个不同的位置，且 <code>2 < 10</code> 。</p> <br><p> </p> <br><p><strong class="example">示例 1：</strong></p> <br><pre><strong>输入：</strong>nums = [1,5,3,9,8], limit = 2<br><strong>输出：</strong>[1,3,5,8,9]<br><strong>解释：</strong>执行 2 次操作：<br>- 交换 nums[1] 和 nums[2] 。数组变为 [1,3,5,9,8] 。<br>- 交换 nums[3] 和 nums[4] 。数组变为 [1,3,5,8,9] 。<br>即便执行更多次操作，也无法得到字典序更小的数组。<br>注意，执行不同的操作也可能会得到相同的结果。<br></pre> <br><p><strong class="example">示例 2：</strong></p> <br><pre><strong>输入：</strong>nums = [1,7,6,18,2,1], limit = 3<br><strong>输出：</strong>[1,6,7,18,1,2]<br><strong>解释：</strong>执行 3 次操作：<br>- 交换 nums[1] 和 nums[2] 。数组变为 [1,6,7,18,2,1] 。<br>- 交换 nums[0] 和 nums[4] 。数组变为 [2,6,7,18,1,1] 。<br>- 交换 nums[0] 和 nums[5] 。数组变为 [1,6,7,18,1,2] 。<br>即便执行更多次操作，也无法得到字典序更小的数组。<br></pre> <br><p><strong class="example">示例 3：</strong></p> <br><pre><strong>输入：</strong>nums = [1,7,28,19,10], limit = 3<br><strong>输出：</strong>[1,7,28,19,10]<br><strong>解释：</strong>[1,7,28,19,10] 是字典序最小的数组，因为不管怎么选择下标都无法执行操作。<br></pre> <br><p> </p> <br><p><strong>提示：</strong></p> <br><ul><li><code>1 <= nums.length <= 10<sup>5</sup></code></li><li><code>1 <= nums[i] <= 10<sup>9</sup></code></li><li><code>1 <= limit <= 10<sup>9</sup></code></li></ul> <br><h3><a id="_59"></a>解题方法：排序</h3> <br><p>对于示例2的<code>nums = [1,7,6,18,2,1], limit = 3</code>，不难发现<code>[1,2,1]</code>这三个元素是一组、<code>[7,6]</code>这两个元素是一组、<code>[18]</code>是一组。</p> <br><p>我们把其中的<code>[1,2,1]</code>排序得到<code>[1,1,2]</code>并放到原来的位置上，<code>[7,6]</code>同理，<code>[18]</code>同理，就得到了结果<code>[1,6,7,18,1,2]</code>。</p> <br><p>怎么确定都哪些元素是一组？排序就好。<code>[1,7,6,18,2,1]</code>排序后是<code>[1,1,2,6,7,18]</code>，从左往右遍历并查看相邻两元素的差值是否大于<code>limit</code>，如果大于则说明需要新分一组。</p> 5]</code>，并按顺序填入<code>[1, 1, 2]</code>即可。</p> <br><ul><li>时间复杂度<span class="katex--inline"><span class="katex"><span class="katex-mathml"><br>     <br>      <br>       <br>        <br>         O<br>

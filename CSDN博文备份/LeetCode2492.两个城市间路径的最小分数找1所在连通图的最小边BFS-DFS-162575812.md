<h2><a id="LetMeFly24921BFS__DFS_1"></a>【LetMeFly】2492.两个城市间路径的最小分数：找1所在连通图的最小边(BFS / DFS)</h2> <br><p>力扣题目链接：<a href="https://leetcode.cn/problems/minimum-score-of-a-path-between-two-cities/" rel="nofollow">https://leetcode.cn/problems/minimum-score-of-a-path-between-two-cities/</a></p> <br><p>给你一个正整数 <code>n</code> ，表示总共有 <code>n</code> 个城市，城市从 <code>1</code> 到 <code>n</code> 编号。给你一个二维数组 <code>roads</code> ，其中 <code>roads[i] = [a<sub>i</sub>, b<sub>i</sub>, distance<sub>i</sub>]</code> 表示城市 <code>a<sub>i</sub></code> 和 <code>b<sub>i</sub></code> 之间有一条 <strong>双向</strong> 道路，道路距离为 <code>distance<sub>i</sub></code> 。城市构成的图不一定是连通的。</p> <br><p>两个城市之间一条路径的 <strong>分数</strong> 定义为这条路径中道路的 <strong>最小</strong> 距离。</p> <br><p><span class="text-only">返回城市</span><span class="text-only text-font-italic"> </span><code><span class="text-only">1</span></code><span class="text-only text-font-italic"> </span><span class="text-only">和城市</span><span class="text-only text-font-italic"> </span><span class="text-only"><code>n</code> 之间的所有路径的 </span><strong><span class="text-only">最小</span></strong><span class="text-only"> 分数。</span></p> <br><p><b>注意：</b></p> <br><ul><li>一条路径指的是两个城市之间的道路序列。</li><li>一条路径可以 <strong>多次</strong> 包含同一条道路，你也可以沿着路径多次到达城市 <code>1</code> 和城市 <code>n</code> 。</li><li>测试数据保证城市 <code>1</code> 和城市<code>n</code> 之间 <strong>至少</strong> 有一条路径。</li></ul> <br><p> </p> <br><p><strong>示例 1：</strong></p> <br><p><img alt="" src="https://i-blog.csdnimg.cn/img_convert/11c1017a910af02bf436684f160dd7da.png" /></p> <br><pre><b>输入：</b>n = 4, roads = [[1,2,9],[2,3,6],[2,4,5],[1,4,7]]<br><b>输出：</b>5<br><b>解释：</b>城市 1 到城市 4 的路径中，分数最小的一条为：1 -> 2 -> 4 。这条路径的分数是 min(9,5) = 5 。<br>不存在分数更小的路径。<br></pre> <br><p><strong>示例 2：</strong></p> <br><p><img alt="" src="https://i-blog.csdnimg.cn/img_convert/c17c84d0ab0e9746be478e0fe6311da6.png" /></p> <br><pre><b>输入：</b>n = 4, roads = [[1,2,2],[1,3,4],[3,4,7]]<br><b>输出：</b>2<br><b>解释：</b>城市 1 到城市 4 分数最小的路径是：1 -> 2 -> 1 -> 3 -> 4 。这条路径的分数是 min(2,2,4,7) = 2 。<br></pre> <br><p> </p> <br><p><strong>提示：</strong></p> <br><ul><li><code>2 <= n <= 10<sup>5</sup></code></li><li><code>1 <= roads.length <= 10<sup>5</sup></code></li><li><code>roads[i].length == 3</code></li><li><code>1 <= a<sub>i</sub>, b<sub>i</sub> <= n</code></li><li><code>a<sub>i</sub> != b<sub>i</sub></code></li><li><code>1 <= distance<sub>i</sub> <= 10<sup>4</sup></code></li><li>不会有重复的边。</li><li>城市 <code>1</code> 和城市 <code>n</code> 之间至少有一条路径。</li></ul> <br><h3><a id="1_59"></a>解题方法：找1所在连通图的最小边</h3> <br><p>由于路径可以无限往返，所以其实只要和<code>1</code>联通的路径都可以走。由于<code>1</code>一定和<code>n</code>联通，所以实际上是找和<code>1</code>联通的节点的所有边中，值最小的那条边。</p> <br><h4><a id="BFS_63"></a>解题方法一：广度优先搜索(BFS)</h4> <br><p>遍历一遍roads得到邻接表<code>graph</code>，其中<code>graph[i]</code>是所有和节点<code>i</code>相邻的<code>节点</code>；同时得到节点相邻最小路长<code>m</code>，其中<code>m[i]</code>是所有和节点<code>i</code>相邻的路的最短距离。</p> <br><p>使用一个队列进行广度优先搜索，初始时把<code>i</code>入队，每出队一个节点就更新答案最小值，并把其相邻未入队过的节点入队。</p> <br><h4><a id="DFS_69"></a>解题方法二：深度优先搜索(DFS)</h4> <br><p>遍历一遍roads得到邻接表<code>graph</code>，其中<code>graph[i]</code>是所有和节点<code>i</code>相邻的<code>(节点, 路的距离)</code>。</p> <br><p>从节点<code>i</code>开始深度优先搜索，遍历每一条与<code>i</code>相邻的路并更新答案最小值，若某条路上与<code>i</code>相邻的节点还未遍历过则递归。</p> <br><h4><a id="_75"></a>时空复杂度分析</h4> <br><ul><li>时间复杂度<span class="katex--inline"><span

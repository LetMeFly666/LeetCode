# MacOS：自定义App快捷键

MacOS上Chrome浏览器一些快捷键和Windows上不太一样(如打开网页源代码我还是习惯`⌘ + U`)，Chrome设置中寻找了一番自定义快捷键无果，才发现原来MacOS和iOS一样有些软件的设置需要进入到系统设置中去设置。

## Chrome自定义`显示源代码`快捷键

第一步：`系统设置` -> `键盘` -> `键盘快捷键`

![`系统设置` -> `键盘` -> `键盘快捷键`](https://files.letmefly.xyz/d/n/blog/MacShortcut/%E8%AE%BE%E7%BD%AE-%E9%94%AE%E7%9B%98%E5%BF%AB%E6%8D%B7%E9%94%AE.jpg)


第二版：`App快捷键` -> `+`，添加Chrome浏览器。

![`App快捷键` -> `+`，添加Chrome浏览器](https://files.letmefly.xyz/d/n/blog/MacShortcut/%E6%9C%80%E7%BB%88%E6%98%BE%E7%A4%BAChrome%E5%BF%AB%E6%8D%B7%E9%94%AE.jpg)

第三步：输入菜单标题、键盘快捷键

![输入菜单标题、键盘快捷键](https://files.letmefly.xyz/d/n/blog/MacShortcut/%E8%BE%93%E5%85%A5%E8%8F%9C%E5%8D%95%E6%A0%87%E9%A2%98%E5%92%8C%E5%BF%AB%E6%8D%B7%E9%94%AE.jpg)

其中这里的`菜单标题`是你在使用Chrome时候在Mac顶部`菜单栏`看到的选项，注意名字不要输错。

![显示网页源代码](https://files.letmefly.xyz/d/n/blog/MacShortcut/%E6%98%BE%E7%A4%BA%E7%BD%91%E9%A1%B5%E6%BA%90%E7%A0%81.jpg)

然后你就可以使用`⌘U`快捷键打开一个网页的网页源代码了。
